## WIP SanChat 

**SanChat is a simple open source discord-like messeneger that you can host for your friends**
---

ALERT: This project in very early development stage, many things may not work for now 


SanChat supports:
- [ ] accounts
- [ ] client-side customization (custom themes(without sync between devices))
- [ ] server-side customization (prepared themes(with sync between devices))
- [ ] text chat
- [ ] media 
- [ ] voice/video chat
- [ ] servers/groups

probably SanChat will not support "friends"
chat is chat but if u want to you can just block people
