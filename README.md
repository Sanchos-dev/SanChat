## WIP SanChat 

**SanChat is a simple open source discord-like messeneger that you can host for your friends**
---

ALERT: This project in very early development stage, many things may not work for now 


SanChat supports:
- [ ] accounts
- [ ] client-side customization
- [ ] server-side customization
- [ ] text chat
- [ ] media 
- [ ] voice/video chat
- [ ] servers/groups
